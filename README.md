# Healthcare Data Analysis Using Python

Healthcare Data Analysis is a practice-based Data Analytics project developed to explore healthcare data, identify meaningful patterns, and generate insights through Python-based data analysis and visualization. This project is part of my continuous learning journey and practical skill development in Data Analytics.

The primary objective of this project is to understand patient demographics, medical conditions, treatment costs, insurance distribution, and hospital admission patterns by performing Exploratory Data Analysis (EDA) on a healthcare dataset.

### Project Activities

**1. Data Cleaning and Preprocessing**
- Understanding the dataset structure, columns, and data types.
- Identifying and handling missing values.
- Checking and removing duplicate records.
- Converting columns into appropriate data types.
- Preparing the dataset for further analysis.

**2. Exploratory Data Analysis (EDA)**
- Analyzing patient age and gender distribution.
- Identifying the most common medical conditions.
- Exploring treatment and billing patterns.
- Analyzing patient distribution across insurance providers.
- Examining monthly average treatment costs.
- Exploring the relationship between patient age and billing amounts.

**3. Additional Analysis**
- Analyzing monthly emergency admissions for capacity planning insights.
- Identifying high-cost patient groups using percentile analysis.
- Exploring emergency admissions with abnormal test results for further review.

### Tools and Technologies

- **Python:** Programming and data analysis.
- **Pandas:** Data manipulation and cleaning.
- **NumPy:** Numerical operations and calculations.
- **Matplotlib:** Data visualization and charts.
- **Seaborn:** Statistical data visualization.
- **Jupyter Notebook:** Interactive development and analysis.

### Project Objective and Learning

Through this project, I am strengthening my practical understanding of data cleaning, data manipulation, statistical analysis, exploratory data analysis, and visualization techniques. It has helped me practice converting raw data into meaningful information and developing an analytical approach to business-related questions.

This is an individual practice project created for educational purposes as part of my ongoing Data Analytics learning journey.
